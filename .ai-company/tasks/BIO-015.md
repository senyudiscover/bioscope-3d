## 1. 目标（一句话）

把上游 `brain.glb`（437 独立结构，CC BY-SA 4.0）做成 BioScope 的第三个独立 3D 模块：**Brain Workbench**，复用 BioScope 既有 Pick / Select / Focus / Fade / Isolate 交互词汇，Anatomy 可 deep-link 进入；不做知识图扩展、不做临床定位。

## 2. Spike 证据基线（2026-09-07，已实测，不得重新争论除非复现失败）

- 完整 CTO spike 报告：分支 `spike/brain-atlas-cto` 的 `.ai-company/reports/BRAIN-ATLAS-SPIKE-REPORT.md`；
  早期 scratch 与 QA 证据：分支 `spike/brain-atlas-integration`、`D:\BioScope-scratch\brain-atlas-tools\`（工具与结果不进 git）。
- 关键实测事实：
  - brain.glb：glTF 2.0，4,650,816 B；`KHR_draco_mesh_compression` required；437 mesh = 563 primitives；每帧 ~2.2–2.7M tris；13 无贴图材质；0 动画/0 皮肤；场景图扁平。
  - metadata↔mesh：437/437 精确匹配；`bx_id` 0..436 唯一，作为**唯一稳定键**（不用 mesh name）。
  - 结构：左 202 / 右 201 / 正中 34；cortex 128、tracts 54、arteries 48、cranial_nerves 44、diencephalon 41、cerebellum 33、brainstem 30、deep_grey 23、veins_sinuses 17、white_matter 9、ventricles 7、meninges_dura 3。
  - 交互：Pick（透明门槛 + 首命中）/ Select / Focus / Fade（其余 0.12 opacity + depthWrite off）/ Isolate（draws → 2）/ Reset 全部在 R3F 栈实测通过。
  - 性能（本机 Intel Iris Xe）：本地 HTTP 加载 wall-clock 0.56–1.22 s；闲置/轨道 76–77 fps；zoom 108 fps；最差"贴近大表面"特写 35–36 fps；raycast 暴力全测均值 11.5–26 ms；console 仅 favicon 404（与 GLB 无关）。
  - 关键坑：多 primitive glTF mesh 在 three.js 加载为 Group，node extras 在 Group 上，**注册时必须沿 parent 上溯**，否则丢 126 个结构（437→311）。
  - License：查看器代码 Apache-2.0；3D 资产 CC BY-SA 4.0，链可溯源；注册结构教学级 ~7 mm，**不得宣称 clinical-grade**。

## 3. Scope

2. **懒加载**：Brain Workbench 进入时才加载 brain.glb + manifest；Anatomy 提供 deep-link 入口（例如 nervous-system 相关入口按钮），不改变 anatomy 场景本身。

## 4. 技术默认（CTO 已定，implementation 遵循）

1. 资产键：`bx_id`（number→string 统一）；manifest 与 GLB 同版本成对提交/部署。
2. 拾取：扁平场景用"可见性 + opacity 阈值 → 首命中"，不套用 `picking-manager` 父子语义打分。
3. 材质：共享材质 + 需要时 per-structure 透明度/强调通道，不盲目 per-mesh clone 全部材质。
4. 交互词汇与 anatomy 对齐：Pick/Select/Focus/Fade/Isolate/Reset；半透明皮层不写深度（depthWrite off）。
5. 署名三处：About/Credits 面板、资产旁 NOTICE、README/文档。
6. 分支纪律：语义化 commit；不 merge `spike/*` 分支本身；GLB/二进制走 local-public，不进 git。
